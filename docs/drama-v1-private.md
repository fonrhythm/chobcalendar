# Drama 前后台拆分（本地开发）

已核对历史聊天及部署审查记录：生产前端为 fonrhythm/chobcalendar，后台为 fonrhythm/chob-calendar-admin。

前端：在现有 App 的区域导航增加仅开发时可见的 DRAMA 入口，展示月历、剧集库和详情，不提供编辑或写入接口。正式构建不启用 Drama。
后台：在现有管理员路由和侧栏加入仅开发时可见的剧集管理；沿用管理员身份限制。另有独立的本机编辑预览入口，供没有配置测试登录服务时检查界面；该入口不被正式构建打包，不是正式权限后台的替代品。

展示调整：Chip 只显示剧名与集数，去除时间、平台和左色条；变动 Chip 仍有划线和变动提示；弹窗海报在前、Cast 标题、移除主演标记，常规文本及标题字号缩小 3px；月份按现有前台的年份、中文大字、英文缩写、前后箭头与今天按钮呈现。

隔离数据：两个开发服务器通过各自的 /__drama_test_data 访问 work/drama-isolated-data.json。前端只读，后台可保存；接口只在开发服务器注册、限制本机来源与同源请求。不是 Supabase 接入，也没有修改线上 schema。原 Calendar 活动仍使用测试示例，真实活动和艺人库接入待完成。

本地开发导航改为 CHOB / Schedule / Drama / About。首页入口同步改为 Schedule 与 Drama。Schedule 默认合并全部地区，在原筛选区增加全部地区、泰国、海外；中国归入海外，保留原始活动 region 字段，不改库。旧 #china / #oversea / #thailand 链接在开发版映射至 Schedule 对应筛选。

Drama 在独立组件内维护月份和剧集库状态，通过 KeepAlive 在切换导航时保留，不使用 Schedule 的视图、地区筛选或数据存储。Schedule 的新增活动浮动入口在 Drama 中隐藏。Drama 开发数据仍只来自本机隔离文件。

导航改动受开发开关约束，正式构建继续沿用原导航及地区行为，未发布。
