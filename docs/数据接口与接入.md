# 数据接口与接入

本期数据流：录入网站（后续开发） → Google Sheets → Apps Script → Vue 展示网站。

## 现有接口状态

项目 .env 与 .env.example 已填入你提供的 /exec 地址。开发环境连接超时，没有拿到可验证的响应。本次实现的输出协议如下；如果已有脚本要求 id、key 等参数，或返回其它字段，需要结合实际脚本进行适配。

浏览器以 GET 请求公开只读接口，不附加认证密钥，不发送写入请求。支持裸数组，或以下包装：

```json
{
  "success": true,
  "updated_at": "2026-09-18T00:00:00Z",
  "data": [
    {
      "id": "sample-event-001",
      "kind": "event",
      "region": "thailand",
      "name": "示例艺人",
      "category": "band",
      "date": "2026-09-18",
      "activity": "示例演出",
      "activity_type": "stage",
      "time": "19:00",
      "end_time": "21:00",
      "venue": "示例场馆",
      "city": "Bangkok",
      "company": "示例公司",
      "type": "现场参与",
      "isofficial": false,
      "images": [],
      "link": ""
    },
    {
      "id": "sample-task-001",
      "kind": "task",
      "region": "thailand",
      "name": "示例艺人",
      "category": "band",
      "date": "2026-09-18",
      "end_date": "2026-09-22",
      "activity": "演出订桌",
      "activity_type": "booking",
      "time": "10:00",
      "contact": "示例订桌账号",
      "contact_method": "联系渠道",
      "isofficial": false
    }
  ]
}
```

日期格式固定为 YYYY-MM-DD，时间建议 HH:mm（24 小时制）。表格中的日期/时间可设置为纯文本，或自定义日期显示为 yyyy-mm-dd、时间为 HH:mm。配套脚本使用显示值，不转换时区。

## 字段

| 字段                     | 规则                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------- |
| id                       | 稳定唯一 ID；修改内容时保留 ID，避免收藏丢失。配套脚本要求必填                                    |
| kind                     | event 日程 / task 事项；配套脚本从来源配置设置                                                    |
| region                   | thailand / china / oversea；配套脚本从来源配置设置                                                |
| name                     | 艺人名，必填，月历标签使用它                                                                      |
| category                 | 艺人分类。泰国/海外：bl、gl、band、singer、group、actor、other；中国：bl、gl、actor、music、other |
| date                     | 开始日期；兼容 start_date                                                                         |
| end_date                 | 可空；不得早于开始日期。跨天事项每天显示                                                          |
| activity                 | 活动/事项名称；兼容 title                                                                         |
| activity_type            | 活动：brand、series、stage、other；事项：ticket、booking、purchase、form、support、other          |
| time / end_time          | 开始/结束时间；time 兼容 start_time                                                               |
| time_status              | private 非公开 / tba 待公布 / all_day 全天；正常有时间时留空                                      |
| type                     | 参与方式，如现场、线上                                                                            |
| company                  | 所属公司，用于筛选                                                                                |
| venue / city             | 场馆与城市                                                                                        |
| contact / contact_method | 联系���象、订桌/报名渠道；contact 兼容 contact_info                                               |
| note                     | 备注；兼容 description                                                                            |
| link                     | 公开购票或活动链接；兼容 ticket_url，仅接受 http/https                                            |
| images                   | 图片 URL 数组，或 JSON 数组字符串，或换行/竖线分隔字符串；兼容 image_url                          |
| isofficial               | 由可信服务端产生的布尔值，不应由普通用户自行指定                                                  |

字段别名是前端兼容项。配套 Apps Script 读取标准列名及代码里列出的少量别名；新表建议直接使用标准字段。
未知艺人分类回退为 other。缺少合法日期、艺人名或地区，结束日期倒置、重复 ID 会使这一轮同步失败并保留旧数据，避免静默丢失活动。

## 使用随包提供的 Apps Script

1. 建立测试表格，每个工作表按首行字段名称填写。普通来源和官方来源分开，事项和日程可分开。
2. 新建 Apps Script 项目，将 apps-script/Code.gs 复制进去。
3. 在项目设置的脚本属性中新增 CHOB_SOURCES。示例值：

```json
[
  {
    "id": "替换成表格ID",
    "tab": "fan-events",
    "kind": "event",
    "region": "thailand",
    "official": false
  },
  {
    "id": "替换成表格ID",
    "tab": "official-events",
    "kind": "event",
    "region": "thailand",
    "official": true
  },
  {
    "id": "替换成表格ID",
    "tab": "fan-tasks",
    "kind": "task",
    "region": "thailand",
    "official": false
  }
]
```

可以增加中国、海外和归档表来源，每个来源设置相应 region。各来源 id+tab+行 id 组合形成全局 ID。

4. 部署为 Web 应用，以表格拥有者身份执行，允许无需登录读取公开日程的访问方式（取决于账号/组织允许的部署选项）。拿到 /exec 地址。
5. 先在未登录浏览器中确认接口返回 success:true 和 data 数组，再把地址放进 .env，重新构建。
6. 开发环境和实际托管域名分别检查请求。Google 内容服务会重定向到 googleusercontent.com，前端已经允许跟随重定向。若当地网络无法访问 Google，这个方案本身无法保证直连稳定，需要下一阶段增加独立缓存服务。

部署与内容服务说明：[Google Web Apps](https://developers.google.com/apps-script/guides/web)、[Google Content Service](https://developers.google.com/apps-script/guides/content)。

脚本仅返回固定公开字段，不包含登录邮箱、用户私密资料或任意其它表格列。不要把私密内容放进公开的 note/contact 等字段。
脚本没有新增、编辑、删除方法。本次不会通过浏览器直接管理表格。

## 官方来源与后续录入权限

官方标识在配套脚本里由 CHOB_SOURCES 的 official 决定，忽略表格行自行提供的 isofficial。来源配置和官方表格只允许管理员或已认证的对应公司维护。公司身份分配必须由后端实现，不能依靠前端按钮隐藏。

后续普通用户新增/编辑、管理员删除、公司单条/批量导入，应通过鉴权后端完成，写入成功后由此只读接口展示。本期不包含这些管理功能，也不包含内容审核队列。

## 同步异常排查

- “同步失败”：网络超时、不是 JSON、返回 success:false、字段不符合协议等。
- “离线缓存”：本次获取失败，正在展示同一接口上次成功保存的数据。
- “演示数据”：用户主动开启的虚构样例。即使接口失败，也不会自动用样例替代实际数据。
- 修改部署代码后更新 Web 应用部署版本；仅保存编辑器代码不代表旧部署已更新。
